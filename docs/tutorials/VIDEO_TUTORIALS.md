## 📋 Prerequisites

Before starting the tutorials, ensure you have:

1. **RageVFX installed** - See [Getting Started Guide](../GETTING_STARTED.md)
2. **System Requirements Met**:
   - Node.js 20.0.0 or higher
   - 8 GB RAM minimum (16 GB recommended)
   - WebGL2-compatible graphics card
3. **Sample Media** - Download the tutorial assets from the `/examples` folder

## 🔧 Recommended Workflow

1. **Watch the video** - Follow along without pausing
2. **Re-watch with practice** - Pause and recreate each step
3. **Experiment** - Try variations on the techniques
4. **Review the guide** - Reference the written documentation
5. **Complete exercises** - Practice with different source material

## 📌 Quick Start Guide

If you're completely new to VFX software:

1. Start with **Episode 1: Getting Started**
2. Complete the **Beginner Tutorials** (Episodes 1-5)
3. Choose a **Learning Path** based on your goals
4. Work through tutorials in order within your path

If you have experience with other VFX tools (Nuke, After Effects, etc.):

1. Skim **Episode 2: Interface Deep Dive**
2. Review **Episode 3: Understanding Nodes**
3. Jump to topics relevant to your needs
