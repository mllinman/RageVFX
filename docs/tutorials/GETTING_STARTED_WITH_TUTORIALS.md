# Getting Started with RageVFX Tutorials

Welcome! This guide will help you get the most out of the RageVFX tutorial series.

## 📚 What's Available

### Written Tutorials
20 comprehensive written tutorials covering beginner to advanced topics:
- **Episodes 1-5:** Beginner fundamentals
- **Episodes 6-12:** Intermediate techniques
- **Episodes 13-20:** Advanced workflows
- **Episode 21:** Bonus - 2D to 3D Stereoscopic Conversion (NEW!)

All written tutorials are in the `docs/tutorials/` directory.

**Status:** Currently in pre-production. Complete scripts and production guidelines are ready.

## 🎯 Choose Your Learning Path

### Path 1: Complete Beginner
**If you're new to VFX software:**
1. Start with [Episode 1: Getting Started](01-getting-started.md)
2. Continue through Episodes 2-5 in order
3. Practice the exercises in each tutorial
4. Then move to intermediate content

**Time:** ~2-3 weeks for beginner series

### Path 2: Compositor Focus
**If you want to focus on 2D compositing:**
- Episodes: 1, 2, 3, 6, 7, 8, 9, 20
- Focus on layering, color, and keying

**Time:** ~3-4 weeks

### Path 3: 3D Artist
**If you want to work with 3D:**
- Episodes: 1, 3, 11, 13, 16, 17, 18, 21
- Focus on 3D pipeline and rendering

**Time:** ~4-5 weeks

### Path 4: Motion Designer
**If you want to create motion graphics:**
- Episodes: 1, 3, 10, 12, 15, 20
- Focus on animation and effects

**Time:** ~3-4 weeks

### Path 5: VFX Generalist
**If you want complete mastery:**
- All episodes 1-21 in order
- Complete all practice exercises
- Build portfolio projects

**Time:** ~3-4 months

## 📖 How to Use Written Tutorials

Each written tutorial includes:

1. **Introduction** - Overview and objectives
2. **Theory** - Concepts and principles  
3. **Step-by-Step Instructions** - Detailed walkthrough
4. **Practice Exercises** - Hands-on activities
5. **Troubleshooting** - Common issues and solutions
6. **Keyboard Shortcuts** - Quick reference
7. **Next Steps** - Where to go next

### Recommended Workflow
1. **Read through** the entire tutorial once
2. **Launch RageVFX** and follow along
3. **Pause frequently** to practice
4. **Complete exercises** at the end
5. **Experiment** with variations
6. **Move to next** tutorial

## 🎬 How to Use Video Tutorials (When Available)

### First Viewing
- Watch the complete video without pausing
- Get an overview of concepts and workflow
- Take mental notes of key points

### Second Viewing  
- Open RageVFX alongside the video
- Pause at each step
- Replicate actions in your own project
- Rewind when needed

### Practice
- Complete the practice exercise
- Try variations on the technique
- Experiment with different settings

### Reference
- Use timestamps to jump to specific sections
- Review challenging parts multiple times
- Keep as a reference for future projects

## 🛠️ Prerequisites

### System Requirements
- **RageVFX Installed** - See Episode 1 for installation
- **Node.js 20.0.0+** - Required to run RageVFX
- **8 GB RAM minimum** - 16 GB recommended
- **WebGL2 GPU** - For 3D and rendering features

### Recommended Setup
- **Dual monitors** - Tutorial on one, RageVFX on other
- **Note-taking app** - For tracking progress
- **Practice files** - Download from `/examples` directory
- **Quiet environment** - For focused learning

## 🎓 Learning Progression

### Week 1-2: Foundation
- Episodes 1-3: Installation, interface, nodes
- Goal: Understand RageVFX basics
- Build: Simple image processing graphs

### Week 3-4: Core Skills
- Episodes 4-5: First effects, export workflow
- Goal: Create and export simple VFX
- Build: Basic composites and effects

### Week 5-8: Intermediate
- Episodes 6-12: Compositing, color, 3D, animation

- Build: Multi-layer composites with effects

### Week 9-12: Advanced
- Episodes 13-20: Physics, ML, motion graphics, workflows
- Goal: Complex production techniques
- Build: Professional-quality VFX shots

### Week 13+: Mastery
- Episode 21 and beyond: Cutting-edge features
- Goal: Specialized advanced skills
- Build: Portfolio-worthy projects
